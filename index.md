## ❓ Troubleshooting
If you encounter any issues, here are some common problems and solutions:

- **Error Message:** "Java not found"
  - Solution: Make sure you installed Java properly. Visit the [Java website](https://www.java.com) to reinstall if needed.

- **The game won't start.**
  - Solution: Ensure all files are extracted correctly and that you are using the correct version of Minecraft.

- **Can't connect to DonutSMP.**
  - Solution: Double-check the server address and make sure you have a stable internet connection.
